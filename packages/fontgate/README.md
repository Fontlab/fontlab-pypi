# fontgate

This distribution is an explanatory stub. `fontgate` is a native binary module
available only inside the FontLab desktop application's embedded Python.
Importing this stub raises `ImportError`; it contains no native implementation.
For external automation, install `fontlab` and use `fontlab-cli`.
Do not install this package inside FontLab's embedded Python.
